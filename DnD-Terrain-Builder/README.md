# D&D Terrain Builder

This example demonstrates a very simple web-based tool for arranging STL files to create custom terrain maps. It uses [Three.js](https://threejs.org/) for rendering.

## Usage

1. Open `index.html` in a modern browser with internet access.
2. Click the file input and select one or more `.stl` files from your computer.
3. The models will appear in the scene and can be repositioned by dragging with the mouse. Use the mouse wheel to zoom and right click to pan.

This is a lightweight demonstration and does not include advanced features like saving the final layout. It can serve as a starting point for a more complete terrain editor.
